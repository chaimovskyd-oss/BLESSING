# Hadish Blessing Designer v0.4.2

גרסה זו משנה את הזרימה ל-Wizard אמיתי עם מסכים נפרדים:

1. בחירת מידה עם הסבר לכל גודל
2. בחירת רקע במסך מלא יחסית
3. בחירת מסגרת / ללא מסגרת
4. מחולל ברכות מלא בתוך הזרימה
5. מסך עיצוב טקסט ויצוא

מה חדש:
- מחולל הברכות משולב כשלב עצמאי.
- דאבל־קליק על ברכה מעביר אותה לעיצוב.
- כפתור דלג/כתיבה חופשית.
- כפתור הדבק ברכה מהלוח.
- Ctrl+C / Ctrl+V / Ctrl+X / Ctrl+A בתיבות טקסט.
- קליק ימני בתיבות טקסט: גזור / העתק / הדבק / בחר הכל.
- מסך טקסט עם Collapsible panels לכותרת, טקסט ראשי, ורקע מאחורי הטקסט.
- Presets בסיסיים לצבע/צל.
- שליטה בגודל כותרת וגוף טקסט.
- צל בסיסי לכותרת ולגוף הטקסט.

התקנה:
```powershell
py -3.10 -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

אם כבר יש venv:
```powershell
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

עדיין לא נכנס:
- בחירת גופנים מלאה מתוך כל פונטי המערכת.
- גרירה חופשית של כותרת/ברכה על הקנבס.
- גרדיאנטים אמיתיים לטקסט.
- שילוב מלא של קוד/ממשק Standalone חיצוני אם יש בו לוגיקה מעבר למאגר המשפטים.
- חיבור ל-SPP / פתיחה ישירה בקנבס הדפסה.
